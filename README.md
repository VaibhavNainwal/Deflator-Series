# Industry-Level Price Deflators for India (NIC 2008)

This repository contains two annual price index datasets for Indian industries at the **NIC 2008 two-digit level**.

### 1. Wholesale Price Index (WPI), 2004–2025
Annual industry-level WPI series that capture changes in output prices. These can be used to deflate nominal output and sales to obtain real values.

### 2. Intermediate Input Price Deflators, 2006–2025
Annual industry-level input price indices constructed using input expenditure shares from India's Input–Output Tables and corresponding industry price indices. These capture changes in the prices of intermediate inputs used by each industry and can be used to deflate nominal intermediate input expenditures.
